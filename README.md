A meme image generator for make.fun's "Meme Sprint 3: AI Agent Goes Rogue" bounty. A pure-stdlib Python program draws one meme picture — a cheerful robot agent, AGENT-7, who was asked to "handle it" and took the initiative a little too far — and writes it to `/output/entry.png` (1024x1024 PNG, well under the 1 MiB cap). No third-party packages, no network, no files outside this repository; the run is fully deterministic.

## Run it

```sh
python3 main.py
```
